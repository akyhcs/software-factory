Let's forget the theory. Let's understand exactly what you are doing in this lesson.

You have a GitHub repository and a Wayfinder board. The next ticket says:

**"Sign up for the notification vendor and provision dev keys."**

The notification vendor is Knock.

### Step 1: You add a new skill

You execute:

```bash
npm run reset add-wizard-skill
```

This adds a file:

```text
.agents/skills/wizard/SKILL.md
```

This file teaches the AI agent how to create interactive setup scripts.

### Step 2: You give the ticket to Wayfinder

You execute:

```text
/wayfinder #42
```

(42 is just an example ticket number.)

The agent reads the ticket and understands:

"I need to help the developer sign up for Knock and obtain development API keys."

It also discovers the wizard skill.

### Step 3: The agent creates a Bash script

Instead of attempting to sign up for Knock itself, the agent creates something like:

```text
scripts/setup-knock.sh
```

This script guides you through the setup.

For example, it might ask:

```text
Welcome to Knock Setup!

1. Open https://knock.app
2. Create an account.
3. Verify your email.

Have you completed signup? (y/n)
```

You enter `y`.

Next:

```text
Open Knock Dashboard.

Navigate to API Keys.

Enter your Development API Key:
```

You paste your API key.

### Step 4: You execute the script

Open another terminal (not the AI agent's Bash terminal).

Run the command generated by the agent, for example:

```bash
bash scripts/setup-knock.sh
```

The script guides you through the process and collects the required information.

### Step 5: Credentials are configured

The wizard saves the required credentials in the project's environment configuration.

For example:

```env
KNOCK_API_KEY=your_secret_key
```

The exact location and variable names depend on the ticket and project.

---

### So what actually happened?

Think of it this way:

| Who? | What do they do? |
|---|---|
| You | Add the wizard skill |
| Wayfinder | Assigns the ticket to the agent |
| AI Agent | Reads the ticket and creates the setup script |
| You | Run the script in another terminal |
| You | Sign up for Knock and retrieve API keys |
| Wizard | Helps configure the credentials |

**The entire purpose of this lesson is to teach the AI agent to generate a setup wizard instead of pretending it can perform tasks that require your personal interaction.**

That's it. No application feature is being developed here. No notification integration is being implemented yet. We're just provisioning the development credentials needed for a future integration.

It's a **project-specific skill provided by the AI Hero course**, not a built-in skill from Matt Pocock or a standard npm skill.

When you run:

```bash
npm run reset add-wizard-skill
```

The command adds the Wizard skill to your current repository.

It creates:

```text
.agents/
  skills/
    wizard/
      SKILL.md
```

### What does this mean?

- **Matt Pocock / AI Hero:** Provides the course and the skill implementation.
- **Reset command:** Restores the repository to a predefined lesson state containing the Wizard skill.
- **Wizard skill:** Contains instructions for the AI agent to generate interactive Bash setup scripts.
- **Your project:** Gets this skill locally inside its `.agents/skills/` directory.

### Can you use this skill in other projects?

Yes. You can copy the `wizard` skill directory into another compatible AI coding agent project.

The important distinction:

**The skill is reusable, but this particular installation command belongs to the course repository.** It isn't a universal command available in every project.
